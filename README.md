# Astral Loop — AddMusic

Music library manager for Astral Loop, an in-game music player for World of Warcraft.

## Installation

1. Install Astral Loop from CurseForge.
2. Download `AddMusic.exe` from [Releases](https://github.com/hooch1303-cmd/AstralLoop-AddMusic/releases/latest).
3. Place it in the `AstralLoop` addon folder, next to `AstralLoop.toc`.
4. Run `AddMusic.exe`, click **Add Folders...** and select your music folders.
5. Click **Scan Library**.
6. If WoW is running, use `/reload`. Type `/astral` to open the player.

## Requirements

- Windows 10 or 11.
- Astral Loop installed.
- Local MP3 or OGG files.

Your music stays in its original folders. No audio files are copied, and the manager is not required during playback.
